# LODs

此示例演示了 Entities Graphics 中的 LODs。

<img src="../../../../READMEimages/LODs.PNG" width="600">

## 它显示了什么？

scene 包含立方体网格，每个 LOD 都有自己的颜色。

## 如何使用这个示例 scene？

1. 在 Hierarchy 中，选择子场景
2. 在 Inspector 中，单击“打开”
3. 在 Hierarchy 中，选择**Root**
4. **根** 包含 100 个 LodGroup 子级，并且在 Inspector 中，请注意 LOD 组 component 附加到它们。
