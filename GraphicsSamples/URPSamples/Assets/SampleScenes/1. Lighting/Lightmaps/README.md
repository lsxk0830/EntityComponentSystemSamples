# 光照贴图

此示例演示了对 Entities 的光照贴图支持。

<img src="../../../../READMEimages/Lightmaps.PNG" width="600">

## 它显示了什么？

scene 包含使用不同光照着色器的球体。scene 还使用烘焙全局照明。

## 如何使用这个示例 scene？

1. 在 Hierarchy 中，选择子场景
2. 在 Inspector 中，单击“**打开**”
3. 转到：**窗口 > 渲染 > 照明**
4. 在 Scene 选项卡中，配置光照贴图设置，单击**生成光照**
5. 保存 scene 和子场景，然后关闭子场景
